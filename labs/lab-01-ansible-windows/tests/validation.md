# Lab 01 Validation Checklist

- [ ] Windows Server VM is running.
- [ ] Mac can reach the Windows Server VM over the network.
- [ ] WinRM HTTPS listener is configured.
- [ ] Firewall permits management access from the Mac.
- [ ] The server certificate is trusted and validated.
- [ ] Ansible and the ansible.windows collection are installed.
- [ ] Credentials are stored securely.
- [ ] Ansible inventory syntax is valid.
- [ ] The connectivity playbook succeeds.
- [ ] IIS installation is tested.
- [ ] Cleanup and rollback procedures are documented.
