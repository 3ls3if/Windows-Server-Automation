# Windows Server Automation Labs

This directory contains independent, hands-on labs built on the
shared automation capabilities in this repository.

## Labs

1. Lab 01 - Ansible Windows Server Configuration
2. Lab 02 - Active Directory Domain Services
3. Lab 03 - IIS Web Server
4. Lab 04 - Windows Patching
5. Lab 05 - Windows Security Hardening
6. Lab 06 - Terraform and Proxmox
7. Lab 07 - Monitoring and Backups

## Lab conventions

Each lab should document:
- Objectives and architecture
- Prerequisites
- Required inventory and variables
- Setup and execution steps
- Validation and expected results
- Cleanup and rollback
- Security considerations

Reuse shared roles and scripts whenever practical.
Never commit credentials, private keys, or unencrypted secrets.
